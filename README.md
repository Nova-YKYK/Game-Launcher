# 🎮 Game Hub

**Game Hub** is a Windows game launcher designed to make managing and launching your PC games easier. Connect your Discord account, organise your games into workspaces, and access your game library from one place.

## ✨ Features

### 🔐 Discord Integration - Sign in using your Discord account. - Automatically restore your saved Discord session when reopening Game Hub. - Keep your game library associated with your Discord account. - Log out whenever you want.

### 🎮 Game Library - Add games using their `.exe` files. - Give your games custom names. - Automatically extract game icons. - Launch games directly from Game Hub. - Edit or remove games from your library.

### 📁 Workspace Manager - Create custom workspaces. - Rename existing workspaces. - Delete workspaces. - Organise games into different workspaces. - Switch between workspaces using the left sidebar. - Use **All Games** to view your entire library.

### 💾 Account-Specific Saving - Save game libraries separately for each Discord account. - Remember workspace organisation. - Keep your game collections organised between launches.

### 🎨 Interface - Modern dark-themed design. - Red accent styling. - Left sidebar navigation. - Scrollable Workspace Manager.
